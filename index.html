Hoodoo 2

A Bryce 2–style 3D landscape studio that runs in your browser. Build a scene from terrains, rocks and primitives in a wireframe window, dress it in the Materials Lab, set the sky and fog, and render it with a progressive GPU ray tracer.

  • Terrain Editor with brushes, erosion and height-map import
  • Materials Lab, procedural textures, boolean groups
  • Live ray-traced viewport, depth of field, snapshots with A/B compare
  • WebM camera movies, autosave, share links, works offline

Hoodoo needs JavaScript and a browser with WebGL2 (recent Chrome, Edge, Firefox or Safari). It is free and open source: source code on GitHub.
